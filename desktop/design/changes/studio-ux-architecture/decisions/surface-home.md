# Surface: Home

首页是紧凑启动中心，不是管理页：

```text
[环境 ▼] [启动方案 ▼] [数据源 / 工作区 ▼] [Start]
```

- 默认只显示三个选择器、服务/前端数量摘要和 Start。
- “调整本次启动”才展开按服务、可视化前端分组的统一启动项列表。
- 临时调整不写回方案；首页记住选择但不自动启动。
- Start 只执行最终清单：先启动未运行服务，再打开多个前端；零服务和零前端均有效。
- 运行中的所选服务复用；未选服务不受影响。一次启动可停止新启动项、重试失败项、查看上下文日志或停止全部。
- 数据源/工作区仍由数据源页管理；启动方案由环境与扩展页管理。
