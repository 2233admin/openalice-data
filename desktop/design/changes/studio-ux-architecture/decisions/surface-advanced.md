# Surface: legacy operational routes

Status: Migration-only, not a normal product surface.

`Advanced` is not a user-facing concept. Backends, Environments, Extensions, API Keys, Jupyter and Logs remain reachable at their existing URLs so old links and native flows continue to work, but normal navigation exposes only `环境与扩展`.

The combined page provides environment-scoped startup plans, service controls and user-facing extension units. It calls the existing Tauri/ODP commands and links to contextual native logs. Do not build a generic Settings page, repair wrapper, API explorer, credential bridge or duplicate lifecycle state machine.
