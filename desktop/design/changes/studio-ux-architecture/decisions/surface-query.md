# Surface: Query

Status: Superseded by the current design baseline.

Query is not an active OpenAlice page or domain object. The current product design treats querying as a source action delegated to an existing ODP/OpenBB API, command, REST/OpenAPI, MCP, Jupyter, or other already-supported consumer.

The earlier standalone Query form, result-evidence panel, history, diagnostics, frontend handoff, and native/composed target union are retained only as historical implementation context. They do not authorize implementation under the current change.
