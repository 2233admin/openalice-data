# OpenAlice Data 产品要求

## 产品边界

OpenAlice Data 是 ODP Desktop 的中文化、人性化 fork。ODP 继续负责受管环境、服务生命周期、凭证安全、扩展安装、能力注册和 Provider 执行；OpenAlice 只组织用户任务和启动选择，不建立第二套数据核心、查询引擎、服务状态机、凭证桥或通用前端协议。

## 正常导航

```text
首页
数据源
环境与扩展
  启动方案
  服务
  扩展
```

原版 Backends、Environments、Extensions、API Keys、Jupyter、Logs 和单独可视化前端页面只保留为旧 URL 的迁移安全入口，不出现在正常一级导航。旧路由继续调用原生页面和 commands，不复制其状态机。

## 首页

首页是紧凑启动中心，顺序固定为：环境 → 该环境下的启动方案 → 数据源/工作区 → Start。

- 默认只显示三个选择器、方案摘要和 Start；摘要说明服务数与前端数。
- “调整本次启动”才展开按服务、可视化前端分组的统一启动项列表。
- 临时调整只影响本次，不覆盖保存的方案。
- 方案属于环境，环境不能整体启动；Start 只执行最终选中的启动项。
- 允许只启动服务、只打开前端或零服务；先处理服务，再打开多个前端。
- 已运行的所选服务复用；未选择的运行服务不受影响。
- 单服务支持停止、重启；失败支持重试和上下文日志。部分失败不阻止其他启动项和前端。
- 支持停止本次新启动、停止用户选择的服务、停止全部；停止本次不能停止本次复用的服务。
- 记住上次环境、方案、数据源和临时调整，但应用打开时不自动执行。
- 原版单 Backend auto-start 不再是正常设置。兼容已有数据时迁入所属环境默认方案并关闭旧标志；不重做安装初始化。

## 启动方案

- 一个环境可以有多个方案；方案只有名称和统一启动项清单。
- 服务和可视化前端是启动项分类，不是两个割裂对象。
- 方案只引用已有服务和当前环境已安装且可启动的前端扩展，不复制命令、端口、环境变量、工作目录，也不保存数据源或工作区。
- 管理位于“环境与扩展”的“启动方案”页签，紧凑列表支持添加、编辑、删除。
- 编辑只有一个“添加启动项”入口，候选按服务和前端分组并支持多选。
- 默认环境、OpenBB API、OpenBB MCP 和安装初始化继续走原版流程；不设计模板、克隆、外部环境接入或新的默认服务系统。

## 数据源

- 数据源是 ODP/OpenBB 原生数据源；Provider × Dataset/API 能力行不成为用户数据源。
- 沿用原版 API Keys 的高密度组件：一个 API Key 数据源一行，多字段凭证只在编辑中展开。
- 工作区是平级分类，也是组合式数据源/数据预配装；同一数据源可属于多个工作区，已有成员关系、路由顺序和批量策略保留。
- 内置数据源统一排在列表底部；新来源先进入全部数据源，未加入工作区的来源显示未分类。
- 主清单保留准确身份、实时/缓存/陈旧/不可用/失败状态以及使用、详情、组合入口；粒度必须是原生数据源/API Key。
- Provider/Router 属于数据源能力，不能在扩展页重复展示。不得新增 query/catalog/workspace 产品。

## 环境与扩展

- 顶部选择环境；至少提供启动方案、服务、扩展三个页签，环境创建/导入/更新/删除作为原版受管 Conda 流程入口保留。
- 服务页签内化 Backends：添加、编辑、删除、启动、停止、重启、重试、状态和日志，继续调用原生 Tauri/ODP commands。
- 环境流程继续支持名称、Python 版本、扩展选择及 YAML、pyproject.toml、requirements.txt 导入；只简化中文步骤和排版，不添加环境模板、复制或任意外部 Python 环境。
- 扩展页只展示用户可识别、主动管理的安装单元：可视化前端、Python Notebook、研究/回测工具等。OpenBB 标准运行组件合并为不可删除的一项；依赖、Provider、Router、openbb-core 和内部组件默认隐藏。
- 前端是可启动扩展，不建立单独前端对象、URL 表单、一级页面或管理协议。Python Notebook 归入扩展，在所属环境中启动/打开/停止，日志附着实例，不进首页普通服务选择。
- 所有日志上下文化，不保留正常一级 Logs。

## 验收

- 正常一级导航只渲染首页、数据源、环境与扩展。
- 首页不自动启动；Start 只调用最终选中的服务和前端，能复用、部分失败、重试和安全停止。
- 启动方案持久化不含服务配置、数据源或工作区。
- 数据源页是 API Key/原生数据源的唯一管理表面，工作区关系不删除原生来源。
- 环境与扩展页能在同一环境上下文管理启动方案、服务和可识别扩展。
- 行为测试覆盖导航、方案持久化、临时调整、服务复用/失败和停止边界；不添加快照或样式细节测试。
