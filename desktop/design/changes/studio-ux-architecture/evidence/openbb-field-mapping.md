# OpenBB field mapping evidence

Status: Historical evidence only; not part of the current OpenAlice Data design baseline.

The repository evidence remains useful for explaining why OpenBB transformations are explicit, but this change no longer proposes a user-facing mapping editor, canonical-field model, compatibility gate, or shared-canonical query.

Current product scope is limited to native data sources and explicit persisted composed data sources that reuse existing ODP/OpenBB routing behavior.

See [`../requirements.md`](../requirements.md) for the active boundary.
