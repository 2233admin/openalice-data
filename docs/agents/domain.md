# Domain Docs

## Before exploring

Read, when present:

- `CONTEXT.md` at the repository root
- `docs/adr/` for decisions relevant to the current area

Missing files are normal. Create them lazily through domain modeling when terminology or architectural decisions are resolved.

## Layout

This is a single-context repository:

- `/CONTEXT.md`
- `/docs/adr/`

Use the vocabulary defined in `CONTEXT.md`. Surface conflicts with existing ADRs instead of silently overriding.
