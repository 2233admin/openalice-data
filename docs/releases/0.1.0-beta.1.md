# OpenAlice Data 0.1.0 Beta 1

发布日期：2026-08-11

这是 OpenAlice Data 的第一个公开 Beta。你现在只需 Docker，即可启动一个基于 OpenBB 的中文数据入口，搜索多市场数据、检查数据源，并请求第一段真实行情。

## Added

- 中文单页数据屏：浏览 Catalog、查看数据集字段、来源、市场、PIT 和查询入口。
- 数据源状态：明确区分可查询、仅目录和未配置，不暴露凭据。
- 真实行情验证：通过 OpenBB yfinance Provider 请求可复现的历史行情。
- 自定义市场入口：区分 OpenBB Provider 和只读 Parquet/DuckDB 两条扩展路径。
- 单服务 Docker Compose：`docker compose up --build -d` 后从 6900 端口访问页面、API 和 MCP。
- Fail-closed 发布验收：容器必须健康、中文页面必须存在、真实 Provider 必须返回数据，否则 CI 失败。

## Changed

- `openalice-data` 包版本升级为 `0.1.0b1`。
- Beta 镜像安装 OpenBB Equity 与 yfinance，并以非 root 用户运行。
- README 改为中文首次使用入口，同时保留 OpenBB 上游、许可证和免责声明链接。

## 立即开始

```bash
git clone https://github.com/2233admin/openalice-data.git
cd openalice-data
docker compose up --build -d
```

打开 <http://localhost:6900/api/v1/data/>。

## 已知限制

- 数据屏暂不保存账户、凭据或远程配置。
- 自定义 OpenBB Provider 仍需编写 Python 适配代码。
- 本项目不提供数据采集调度、交易、持仓或下单能力。
- 第三方数据权利不随开源代码自动获得，使用前请阅读 [免责声明](../../DISCLAIMER.md)。

## Compatibility

既有四个 OpenAlice Data MCP 工具保持不变；Python 支持 3.11–3.13。本版本没有已知破坏性 API 变更。
